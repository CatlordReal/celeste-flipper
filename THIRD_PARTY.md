# Sources and attribution

- **Celeste Classic**: Maddy Thorson and Noel Berry, original PICO-8 game.
- **ccleste**: https://github.com/lemon32767/ccleste, commit `261d96f15af430b8111abc7a5250229246654f52`. `vendor/celeste.c`, `vendor/celeste.h`, `vendor/tilemap.h`, `vendor/UPSTREAM.md`, `tests/upstream-tas.txt`, and converted BMP data in `assets.h` derive from that source. The game adapter appends checkpoint accessors, restores completed/chest state, shares the single chest particle buffer, removes unavailable diagnostic output, and makes map data const. Physics remains upstream's float implementation.
- `assets.h` is generated by `scripts/generate_assets.py` from upstream `data/gfx.bmp` and `font.bmp`, padded to 128x128 without changing source indices.
- Monophonic music data in `audio.c` is a simplified cartridge-pattern arrangement; source/provenance is retained in that file. The stock speaker does not reproduce the original four channels.
- **Independent Windows install**: official ccleste v1.4.0 `ccleste-win.zip`, https://github.com/lemon32767/ccleste/releases/download/v1.4.0/ccleste-win.zip. SHA-256 `73f07ddf101fb8274e3341f701bde62a83477b695cff42b172b48680995f1ec7`. The portable build downloads and embeds this unchanged archive; it is not part of Flipper execution.
- **Momentum**: https://github.com/Next-Flip/Momentum-Firmware, `mntm-012`, commit `e1784e7418d8b074e971983ceb6fef0f37e52ae4`. SDK API 87.1. Firmware is not redistributed or flashed here. Notification, Dolphin and USB APIs are linked dynamically.
- **Go serial**: https://github.com/bugst/go-serial, v1.6.4, BSD-3-Clause; dependencies and hashes are pinned in `portable/native/go.mod` and `go.sum`.

## iPhone icon

`ios/upstream-icon.png` is the original `icon.png` from the same upstream [ccleste repository](https://github.com/lemon32767/ccleste/blob/master/icon.png). The iPhone asset preserves those pixels with nearest-neighbor scaling and an 8% smaller image on a black background. Original Celeste Classic art is credited to Maddy Thorson and Noel Berry.
